# 数学中的Current与de Rham上同调关系

您好，这是一个非常深刻且优秀的数学问题，它触及了现代几何分析的核心。我将分步详细解释这些概念。

### 1. 什么是数学中的 “Current”？

在数学中，**Current**（中文常译为“流”或“电流”，但在此语境下保留英文术语）是**分布（Distribution）概念在微分形式上的推广**。

为了理解它，我们最好先回顾一下大家更熟悉的概念。

#### 先修知识：施瓦茨分布（Distribution）

在偏微分方程理论中，一个**分布**（或称“广义函数”）不是一个经典的函数，而是一个**作用于光滑函数空间的线性泛函**。更准确地说：

*   设 $\Omega$ 是 $\mathbb{R}^n$ 上的一个开集。
*   令 $\mathcal{D}(\Omega)$ 为 $\Omega$ 上具有紧支撑的光滑函数（测试函数）空间。
*   一个**分布** $T$ 是一个线性映射 $T: \mathcal{D}(\Omega) \to \mathbb{R}$，它满足某种连续性要求（在分布拓扑下连续）。

例如，狄拉克 $\delta$ 函数就是一个分布，它定义为：$\langle \delta, \phi \rangle = \phi(0)$ 对于任意测试函数 $\phi$。

#### Current：分布的推广

现在，我们将这个思想从函数提升到**微分形式**。

*   令 $\mathcal{D}^k(\Omega)$ 表示 $\Omega$ 上具有紧支撑的**光滑 k-形式**（测试形式）的空间。
*   一个 **k-维的 current** $T$ 是一个线性映射 $T: \mathcal{D}^k(\Omega) \to \mathbb{R}$，它满足相应的连续性要求。

你可以这样理解：
*   **分布** 是 **0-形式**（即函数）上的线性泛函。
*   **Current** 是 **任意 k-形式** 上的线性泛函。

#### Current 的直观例子

1.  **光滑形式作为 Current**：
    任何一个光滑的 $(n-k)$-形式 $\alpha$ 都可以自然地看成一个 $k$-维的 current $T_\alpha$，其定义如下：
    $$
    \langle T_\alpha, \omega \rangle = \int_{\Omega} \alpha \wedge \omega
    $$
    其中 $\omega$ 是任意一个紧支撑的 k-形式。特别地，一个光滑函数 $f$ 定义了一个 $n$-维的 current。
    
2.  **子流形作为 Current**：
    设 $M$ 是 $\Omega$ 中的一个定向的 $k$-维子流形（可能带有边界）。那么 $M$ 定义了一个著名的 $k$-维 current $[M]$，称为**积分 current**：
    $$
    \langle [M], \omega \rangle = \int_M \omega
    $$
    这个简单的定义具有巨大的威力。它允许我们使用微分形式的语言来研究子流形的几何性质。
    
3.  **更奇特的例子**：
    Current 可以表示很多没有经典几何意义的结构。例如，一个“点电荷”可以看作一个 $0$-维 current（作用于函数上），而一个“涡旋线”或“曲面上的张力”可以模型化为更高维的 current。

### 2. Current 和分布（Distribution）的联系

它们的联系非常直接且深刻：

**分布是 $0$-维的 Current。**

*   一个分布 $T$ 是作用于 **$0$-形式**（测试函数）的线性泛函。
*   一个 k-维的 current 是作用于 **$k$-形式** 的线性泛函。

因此，**Current 理论是分布理论的扩展和一般化**，将泛函的作用对象从函数推广到了微分形式。所有处理分布的技巧（如弱导数、卷积正则化等）都可以相应地推广到 current 上。

### 3. 什么是 Current 版本的 de Rham 上同调？

首先回顾光滑的 **de Rham 上同调** $H^k_{dR}(M)$：
它定义为闭 $k$-形式的空间除以恰当 k-形式的空间：
$$
 H^k_{dR}(M) = \frac{ \ker(d: \Omega^k(M) \to \Omega^{k+1}(M)) }{ \operatorname{im}(d: \Omega^{k-1}(M) \to \Omega^k(M)) } 
$$
它刻画了流形 $M$ 的拓扑不变性。

现在，我们定义 **Current 的 de Rham 上同调**：

1.  **外微分 $d$**： 我们可以定义 current 的外微分。对于一個 $k$-维的 current $T$，我们通过**对偶性**来定义它的微分 $dT$，使其成为一个 $(k+1)$-维的 current：
    $$
    \langle dT, \omega \rangle = (-1)^{k+1} \langle T, d\omega \rangle
    $$
    这个定义模仿了斯托克斯定理：$\int_M d\omega = \int_{\partial M} \omega$。这个定义使得微分算子 $d$ 在 current 上始终有定义。
    
2.  **闭 Current 与恰当 Current**：
    *   如果一个 current $T$ 满足 $dT = 0$，则称其为**闭的**。
    *   如果一个 current $T$ 可以写成 $T = dS$，其中 $S$ 是另一个 current，则称其为**恰当的**。

3.  **Current 上同调群**：
    利用上述定义，我们可以完全仿照光滑的情形来定义上同调群：
    $$
     H^k_{dR, \, \text{current}}(M) = \frac{ \{ \text{k-维闭 current} \} }{ \{ \text{k-维恰当 current} \} } 
    $$
    

### 4. 为什么它和光滑的 de Rham 上同调同构？

这是整个理论最精彩的部分之一，其核心思想是：**光滑形式在 current 空间中是稠密的**。

有两个关键定理：

**定理一： de Rham 定理（Current 版本）**
流形 $M$ 的 **current 上同调群** 与它的**奇异上同调群**（特别是实数系数）是自然同构的。

**定理二： 光滑 de Rham 定理**
流形 $M$ 的 **光滑 de Rham 上同调群** 也与它的**奇异上同调群**自然同构。

既然它们都与同一个对象（奇异上同调）同构，那么它们彼此之间也自然是同构的：
$$
 H^k_{dR}(M) \cong H^k_{dR, \, \text{current}}(M) 
$$


#### 为什么可以建立这个同构？

具体的同构映射非常直接：

*   **从光滑到 Current**： 将一个光滑的闭 $k$-形式 $\alpha$ 映射到它对应的 current $T_\alpha$（即积分泛函）。因为 $d\alpha = 0$，根据定义有 $dT_\alpha = 0$，所以 $T_\alpha$ 定义了一个 current 上同调类 $[T_\alpha]$。
    $ \iota: H^k_{dR}(M) \to H^k_{dR, \, \text{current}}(M), \quad [\alpha] \mapsto [T_\alpha] $

*   **证明同构**： 要证明 $\iota$ 是一个同构，需要证明：
    1.  **满射**： 任何一个 current 上同调类 $[T]$ 都包含一个光滑的代表元。也就是说，存在一个光滑的闭形式 $\alpha$，使得 $[T] = [T_\alpha]$。这之所以成立，是因为我们可以用光滑的形式去“正则化”或“逼近”一个 current。这个过程依赖于“**拉回**”和“**投射**”的光滑性，以及**单位分解**等工具。
    2.  **单射**： 如果 $[T_\alpha] = 0$，即 $T_\alpha = dS$ 对于某个 current $S$，那么必然有 $\alpha = d\beta$ 对于某个光滑形式 $\beta$。这表明光滑形式类的 $[\alpha]$ 本身也是零。

这个同构的意义非常深远：它意味着**上同调的不变量完全由光滑结构决定**。即使我们允许使用像“子流形”甚至更奇异的对象（如 Current）来代表上同调类，最终每一个这样的类都可以用一个光滑的微分形式来唯一表示。这为我们在几何分析中使用更一般的对象（如极小流形、变分问题中的弱解）提供了坚实的理论基础，因为我们可以期待最终的解是光滑的。

### 总结

| 概念         | 分布 (Distribution)     | 流 (Current)                                       |
| :----------- | :---------------------- | :------------------------------------------------- |
| **作用对象** | 光滑函数 ($0$-形式)     | 光滑微分形式 ($k$-形式)                            |
| **本质**     | 广义函数                | 广义微分形式/广义子流形                            |
| **例子**     | 狄拉克 $δ$ 函数         | 子流形的积分泛函 $[M]$                             |
| **关系**     | 分布是 $0$-维的 Current | Current 是分布的推广                               |
| **上同调**   | -                       | $H^k_{dR, \, \text{current}}(M) \cong H^k_{dR}(M)$ |

Current 的理论由 Georges de Rham 本人开创，并被赫伯特·费德里希（Herbert Federer）和 Wendell Fleming 等人发展成为**几何测度论**这一重要学科的基础工具，为研究极小曲面、变分问题等提供了强大的框架。
